# Esperança para Todos

## Apresentação do projeto

O projeto Esperança para Todos é um site desenvolvido para apresentar uma ONG,
sua missão, seus projetos e formas de participação. O site também possui uma
página de cadastro para voluntários.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript. O HTML5 foi utilizado para estruturar as páginas, o CSS3 para a estilização e o JavaScript para adicionar funcionalidades e interatividade ao site.

## Estrutura do projeto

O projeto está organizado em pastas para facilitar a localização e a manutenção dos arquivos. A pasta `html` contém as páginas do site, a pasta `css` contém os arquivos de estilização, a pasta `js` contém os arquivos JavaScript e a pasta `imagem` contém as imagens utilizadas no projeto.

## Funcionalidades

O site apresenta informações sobre a ONG, seus projetos, formas de participação e canais de contato. Também possui um formulário para cadastro de voluntários, com validação dos campos e armazenamento dos dados utilizando JavaScript e LocalStorage.

## Execução do projeto

Para executar o projeto, basta abrir a pasta no Visual Studio Code e utilizar um servidor local, como o Live Server. Depois, é possível acessar o site pelo navegador.

## Formulário de cadastro

O formulário permite que o usuário informe seus dados pessoais e de endereço para realizar o cadastro como voluntário. O JavaScript realiza a validação dos campos obrigatórios e o LocalStorage permite armazenar e recuperar os dados cadastrados.

## Organização do JavaScript

O código JavaScript foi dividido em arquivos com diferentes responsabilidades. O arquivo `script.js` é responsável pela navegação e carregamento do conteúdo, `formulario.js` cuida da configuração e validação do formulário e `armazenamento.js` é responsável pelo armazenamento dos dados no LocalStorage.

## Considerações finais

O projeto foi desenvolvido com o objetivo de criar uma página de apresentação para a ONG Esperança para Todos, utilizando tecnologias básicas de desenvolvimento web e organizando os arquivos de forma modular.
